# Gloria Beans Coffee Store

A modern, responsive coffee store website showcasing premium coffee products and franchise opportunities. Built with plain HTML, CSS, and Google Fonts with no external frameworks dependencies.

## ✨ Features

- **Responsive Design** - Adapts to different screen sizes
- **Modern Typography** - Google Fonts integration (Caveat & Rubik)
- **Image Gallery** - Product showcase with hover effects
- **Franchise Slider** - Interactive image carousel
- **Contact Section** - Team contributor profiles
- **Clean UI** - Minimalist design with coffee-themed colors

## 🚀 Getting Started

### Prerequisites

- Basic knowledge of HTML & CSS
- A code editor (VS Code recommended)
- A local web server (optional but recommended)

### Installation

1. Clone or download this repository
2. Open the project folder in your code editor

### Running Locally

**Method 1 - Simple Local Server**
```bash
# Using Python 3
cd "E:\Portfolio Projects\Full Stack\gloria-beans-coffee-store"
python -m http.server 8000
```

**Method 2 - Open Directly**
Simply open `index.html` in your web browser.

**Method 3 - Live Server Extension (VS Code)**
Install the "Live Server" extension and click "Go Live" in the browser.

## 🎨 Customization

### Changing Images
Replace images in the `Images/` folder with your own content.

### Updating Links
Modify the `href` attributes in the HTML files to update hyperlinks.

### Brand Colors
Update colors in the CSS files:
- Main background: `rgb(236, 205, 137)` (gold/light brown)
- Dark areas: `rgb(0, 0, 0)` (black)

### Fonts
Adjust fonts in `<head>` sections using Google Fonts:
```html
<link href="https://fonts.googleapis.com/css2?family=Caveat&display=swap" rel="stylesheet">
```
